name: Welcome message media
description: User requirement for a linked welcome image and a single-message greeting.
---

The user wants a dashboard image-link field that puts the image above the welcome text, and explicitly said “remember all is 1 message only.”

**Why:** The user asked to keep the complete welcome together, not send a separate image, title, text or automatic product list.

**How to apply:** Use one photo/GIF message with the full welcome as its caption and its menu attached. Without an image, keep one text message. Validate caption limits before saving rather than truncating the merchant's welcome or splitting it. Do not add an automatic second catalog message after `/start`; customers can open Products from the menu.
