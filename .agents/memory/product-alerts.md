---
name: Product announcement wording
description: User-approved timing and distinct labels for new products versus restocked products.
---

Wait until an active product has stock before announcing it. The user chose “Wait until stocked.”

**Why:** An empty product must not be advertised as ready to buy.

Use “New product” for the first stocked announcement and “Added stock” for subsequent inventory additions to an existing product.

**Why:** The user explicitly requested different wording rather than the same “New in stock” heading for both events.

**How to apply:** Remember the distinction across restarts and sold-out periods; becoming available again does not make an existing product new.

Product images should be configured with an optional direct public HTTPS link in the dashboard, including `.gif` links, not by uploading to a storage bucket. Send each stock alert and Buy now product card as ONE message with the name and description in the photo/GIF caption, not a separate name message.

**Why:** The user explicitly chose image links, including GIFs, instead of creating a bucket. They corrected the separate name message and said to make it one message.

**How to apply:** Put the name, description and purchase/stock details together in a single media caption, keeping inline actions attached. Keep captions within Telegram's limit by bounding description previews; do not split the product name into its own message.

Scheduled product promotions are separate from stock-change announcements. The user wants configurable sending intervals, product advertising enable/disable controls, and random product cards sent to customers with a Buy button, including individual options inside grouped products. Promotional cards must not say “Added stock” or “New product.”

**Why:** The user requested recurring advertising resembling the existing product card, without stock-event labels.

**How to apply:** Reuse the single-message product-card presentation and the correct option's price, stock and purchase identity. Keep scheduled promotion wording distinct from actual stock-event announcements.
